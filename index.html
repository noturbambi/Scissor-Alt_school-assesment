! FAQs

How does URL shortening work?

URL shortening converts a long web address into a shorter link that redirects to the original destination when opened.

Is it necessary to create an account to use the URL shortening service?

You can try basic link shortening without an account. Creating an account gives you access to link management and analytics features.

Are the shortened links permanent? Will they expire?

Shortened links remain available according to the service plan and account settings associated with them.

Are there any limitations on the number of URLs I can shorten?

Usage limits depend on your plan. The Basic plan includes the features listed in the pricing section.

Can I customize the shortened URLs to reflect my brand or content?

Yes. Custom aliases and branded domains help make your links recognizable and easier to remember.

Can I track the performance of my shortened URLs?

Scissor analytics help you understand link clicks, scans and audience engagement.

How secure is the URL shortening service? Are the shortened links safe to use?

Use links from sources you trust and review the destination before sharing sensitive information.

What is a QR code and what can it do?

A QR code is a scannable code that can quickly open a website or other linked information on a mobile device.

Is there an API available for integrating the service into my own applications?

API availability and access depend on the selected plan and the service's developer options.
